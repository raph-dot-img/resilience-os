# The graphical interface

Some computers run the graphical edition of Resilience. It looks different
from the text interface, but it is the same system: the same sections,
the same tools, the same security modes. Everything in this handbook
applies to both.

THE MAIN SCREEN
  Large tiles, one per section (Knowledge, Networking, Security ...).
  Click a tile, or move with the arrow keys and press Enter.
  The search box at the top right finds apps, sections and handbook
  pages. Click it and type, or press / anywhere.

GETTING AROUND
  Back (top left) or Esc     go back one screen
  Home (top left)            go straight back to the main screen
  Arrow keys                 move between tiles
  Enter                      open the highlighted tile
  F1                         help for the current screen

LISTS AND CHOICES
  Every list works the same way: click a row, or move with the arrow
  keys and press Enter. The keys of each screen are shown at its top
  right. In lists with ticks (resource packs, packs of a nearby
  computer, who to encrypt for), a click or Space ticks a row.

QUESTIONS AND CONFIRMATIONS
  Questions open in a box over a dimmed screen. Cancel is always the
  default: pressing Enter on a confirmation does nothing harmful. Press
  y (or click the coloured button) to confirm, n or Esc to cancel.

SCREENS THAT LOOK LIKE THE TEXT INTERFACE
  The licence notice, the installer and the table viewer (CSV files)
  are still shown in the text interface's style, inside the window.
  They work as described in the rest of this handbook: use the keys
  shown at the bottom of the screen.

PROGRAMS
  An editor, a game or a tool opens in its own window on top of
  Resilience. When you quit it (each program's description says how), you
  are back where you were.

PASSWORDS
  When something needs a password (an administrator's, a passphrase to
  encrypt), it is asked in a window like the programs above, never by
  the main screen itself.

IF THE SCREEN STOPS RESPONDING
  The graphical interface restarts by itself. If it fails three times in
  a row, the text interface starts instead, and your files are safe.
  Ctrl+Alt+F2 (up to F6) always gives a text login on another console;
  Ctrl+Alt+F1 comes back to the graphical screen.
